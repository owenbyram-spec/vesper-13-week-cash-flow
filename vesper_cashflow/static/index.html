OPTIONAL CONNECTIONS
A little setup. Then context.
Choose an entity first. Keys go directly to this local backend. Persistent secrets use your OS credential store; when unavailable, choose session-only storage. No plaintext fallback.
01 / Embedded AI
  1. Create an API key in your own OpenAI account.
  2. Check API pricing and available usage limits. Your API account pays for requests.
  3. Save, then test the connection. Replace a revoked key here; work remains saved if a request fails.
Local app operation does not mean local model inference. Synthetic rehearsal remains available without a key.
02 / QuickBooks Online (read only)
  1. Create your own Intuit developer app. Start with a sandbox company.
  2. Register the exact redirect https://developer.intuit.com/v2/OAuth2Playground/RedirectUrl.
  3. Use the official OAuth Playground to authorize Accounting access and obtain your Realm ID and refresh token. See Intuit’s setup guide.
  4. Enter your own app credentials, test, and explicitly confirm the returned company. Production access depends on Intuit’s app and company eligibility.
Current AR/AP balances support today’s forecast only. Cash dates still require your review. Missing payroll, rent, tax, financing and sales assumptions remain visible. Multiple requests are not an atomic accounting snapshot.
Connection status & recovery
Invalid key: replace and test. Usage limit: check your provider account. Expired or revoked QBO grant: authorize again in the official Playground, replace the connection and confirm the company. Incomplete accounting reads preserve the previous forecast.


Restore a verified backup
Restoration validates all forecast hashes and creates a separate entity. Existing work is preserved. Proposal history stays in the backup as evidence; saved forecast versions are restored.


Your local workspace
Financial data and versions live in a SQLite database outside the source checkout. Backups contain financial data; store them appropriately. Export does not include API keys.
AI requests send your message and scoped tool results to your configured model provider after your consent. Accounting refresh contacts Intuit. No shared Vesper credentials or hosted service is included.
This is a single-device utility. Locally typed names do not establish verified identities or separate preparer/approver roles. Weekly ending cash may hide intraweek shortfalls; review payment dates before acting.
Delete the active entity
Export a backup first if you need it. This removes the active entity’s local inputs, versions and decisions. Its saved local connections are also removed and polling stops. Revoke the grant in Intuit if you also want to revoke provider access.
