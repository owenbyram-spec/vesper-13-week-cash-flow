# Security and responsible use

Run this app on a device and OS account you control. It binds to loopback and uses local session/origin/CSRF checks. Never expose its port publicly or treat it as shared hosted team software.

Secrets use the OS credential store or session memory. Protect local data/backups and review files before publication. AI proposes; deterministic code calculates; humans review material decisions. No accounting writeback is included.

Report suspected vulnerabilities privately to Vesper & Co through your existing contact. Do not publish credentials, client data or an exploit containing sensitive records in a public issue.
